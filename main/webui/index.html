Saving writes the mrb_script partition and reboots the board to apply it - same effect as bin/upload_mruby_script.py, but over WiFi instead of serial. The board is unreachable for a few seconds while it restarts; refresh this page once it's back. Syntax highlighting is loaded from a CDN (cdn.jsdelivr.net) - if this network has no internet access, editing still works as a plain textarea.

"Sleep now" manually triggers the USB-suspend power-saving reaction (WiFi off) - use it if you connected to a PC that was already suspended before this board booted, since that never fires the automatic detection (only a live suspend/resume transition does). WiFi stops shortly after, so this page becomes unreachable until the PC actually resumes; only use it when the PC really is suspended, or it'll stay off until reset.
